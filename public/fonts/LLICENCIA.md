# Fonts

Both faces are free software under the SIL Open Font License, version 1.1
(https://openfontlicense.org), which allows them to be used, embedded and
redistributed with the site.

- **Bricolage Grotesque**: https://github.com/ateliertriay/bricolage
- **Figtree**: https://github.com/erikdkennedy/figtree

The files are the ones Google Fonts serves for the weights the site uses
(Bricolage Grotesque 700–800, Figtree 400–700), latin and latin-ext only.
